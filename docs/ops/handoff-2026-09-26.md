## Product Owner decisions, second round (same day)

- **Decision 3 revised:** four states, grounded in the Scrum Guide 2020
  ("Product Backlog items that can be Done by the Scrum Team within one
  Sprint are deemed ready for selection in a Sprint Planning event"; the
  Sprint Backlog is "the set of Product Backlog items selected for the
  Sprint"; an item not meeting the Definition of Done "returns to the
  Product Backlog") and the ScrumPLoP "Definition of Ready" pattern
  (six criteria before an item is a Sprint candidate): empty = ordinary,
  `Ready`, `In Progress`, `Done`. Applied everywhere; the parser no longer
  flags several `In Progress` rows (a Sprint holds several).
- **Decision 4 revised:** Mailjet sub-account credentials go to Railway
  project variables, not Bitwarden.
- **Decision 10:** dependencies allowed, each recorded in the new
  dependency register (architecture section 8) with alternative and
  removal cost; "stdlib only" superseded. The repo file is one backlog
  source among others: `BacklogSource` port added to the architecture.
- **Landing:** `/` now renders the pitch plus the demo backlog through the
  single board engine; `/demo` redirects to `/`. No separate landing
  backlog implementation exists or will.
